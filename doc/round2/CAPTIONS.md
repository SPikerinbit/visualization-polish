## E4a 移出

画出的 β 是 `{0, 0.25, 0.5, 0.75, 1}`。`β=0.1` 和 `0.9` 留在数据文件里，没有画。两点重合表示两个角色选了同一个 `(k,h)`。这张切片不是 `n=100` 样本。`(8,1)` 与 `(8,2)` 在 `m=20` 时至少要有 8 条 run 才合法：`n=500`（25 条 run）成立，`n=100` 不成立。

## E4c 移出

DL20 与 COVID 的数据集级占位按 `1/2` 等权，费用和质量分开平均。没有存 query 行，所以不是六条 query 的均值，也不画逐 query 云。两张 Full 共用 Spearman 轴限，两张 LIMIT 10 共用 NDCG@10 轴限，四张共用 token 轴。ListK Fig. 4 把红点线叫 Pareto frontier，并且把线画出点外。这里的红虚线只连接非支配均值（费用不升、质量不降），并停在这些均值上。Full Off 连接 LT、SW、ListK。LIMIT 10 On 连接 SW、Tournament、ListK。Full On 与 LIMIT 10 Off 各自只有一个非支配均值（SW）。

## E5 移出

NDCG@10 在每个端点（含 Full）用同一个窗口。SW 与 LT 的 Full 标记被推进 Full 带内，使两者都看得见；每条带仍只有每个方法的一个 Full 观测。LIMIT 标签转 60°，使 490 与 500 在这个宽度上分开。格子是单个占位数，不是实验所要求的三 query 均值。
