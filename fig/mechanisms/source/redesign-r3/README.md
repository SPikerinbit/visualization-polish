# R3 mechanism challengers

All alternatives use the examples from the pre-redesign review. SW retains the
three original rounds and exposes the emit boundary and the next refill.
LT shows a three-step refresh in place of the middle tree; the two side trees
are the original pre- and post-refresh states. Pointer separates ranked winners
from the full-list slot exhaustion that selects the next child.

For editable art use the SVGs; rebuild with Inkscape and a serif font indicated
in the source. The Python renderers write outputs next to their sources, without
changing the manuscript assets. The selected files are SW A2-window-large, LT
lt-bold-r3, and Pointer pointer-A.
