# Figure 1 · adversarial print review and structural alternative
Evidence reviewed at the same final width: R1 (main-equivalent) p.2, R12 p.2, and original source crops below. This is a judgment about this particular figure, not a publication or acceptance prediction.

## Specific print failures
- In R12, candidate B and C depict a flat four-way star. The LT in §3 is binary, and its height and replay path matter for the bound. R1's nested binary split was more accurate. At physical size neither h encoding is strong enough in R12; different labels should not be the only reliable way to tell the handles apart.
- The lower candidate row is detached from the upper decision. The repeated-token inset and its 5.20-pt caption explain an accounting example rather than how these three concrete objects participate in planning. R12 devotes visual emphasis to a box marked “Minimum cost”, not to the comparison or to the accounting distinction.
- Three differently labelled stages cover three local layouts. Yet two groups of shapes that ought to be compared, Full and LIMIT, are stacked vertically with different baselines, output routing and label positions. The semantic contrast takes two readings. The weakest ink is allocated to the idle peers and the per-request distinction.
- Error-prone at actual size: R12 layer barrier 5.36 pt; input definitions 5.52 pt; repeated item 5.20 pt. R12 uses Nimbus Roman while the manuscript uses Linux Libertine. These are PDF text measurements, not a screenshot estimate.
- The selected-plan connector is intentionally **not** a non-negotiable prohibition: an older meeting requested removal, but newer design feedback changed the implementation. The challenger carries the relation with mode-specific labels, not an elbow ending at a heading.

## Transfer / reject
- [CrocSort Fig. 3](https://www.vldb.org/pvldb/vol19/p2978-otaki.pdf#page=4): repeated objects acquire meaning from persistent track positions. Reuse stable tracks for the same selected layers/groups; don't copy thread semantics or make every line an arrow.
- [SIEVE Fig. 4](https://www.vldb.org/pvldb/vol18/p4723-li.pdf#page=4): an intermediate object visibly participates in an operation. Make candidates feed the common estimator; don't copy its heavy nested frames or draw an offline phase unless the manuscript specifies it.
- [Self-RAG Fig. 1](https://arxiv.org/abs/2310.11511): matched baseline/alternative contrasts make a changed action local. Put Full and LIMIT side by side against one set of layer labels; don't borrow decorative token colors or paper illustrations.
