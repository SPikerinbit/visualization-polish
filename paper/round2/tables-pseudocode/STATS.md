## 三种指标共用的序位规则

每个模型、每个需求、质量 / token / latency 各自独立排序。质量、token、latency 的拆平条件相同：只有六维原始向量已经相同，并且每个并列方法在六个数据集上都有合法重复次数，才允许用更小的离散度拆开。缺次数不是合法次数。离散度不是显著性。

1. 数据集内部按未舍入均值排名。质量越大越好，token 和 latency 越小越好。完全相等用 midrank。这一步不用排列标准差，也不用重复方差。
2. 主键是六集 midrank 的等权平均，用分数保存。印出的整数是竞赛名次：1 加上严格更好的方法数。它不是平均名次的四舍五入。任一数据集缺失则该方法在该指标上不合格，印 `---`，不用其余五集重新加权。
3. 主键相同才看次键。质量：Spearman 写成 `(ρ+1)/2`，或使用仍在 `[0,1]` 内的 nDCG，再取六集平均，越大越好。nDCG 超出 `[0,1]` 直接拒绝，不做 min-max。Token 和 latency：六集均值的平均，越小越好。
4. 次键仍相同：按 Q9、DL20、DL22、COVID、DBpedia、Robust04 的原始均值做字典序，方向与该指标一致。
5. 六维向量仍相同，并且每个并列方法在六个数据集上的重复次数都存在且至少为 2：质量用更小的平均排列标准差（`n_permutations ≥ 2`），token 和 latency 用更小的平均重复方差（`n_repeats ≥ 2`）。六个次数全部缺失时，即使标准差或方差已经写上，也不使用。只有一方次数不足同样不使用。
6. 到这里仍相同：共用一个整数，下一个整数跳过。方法名、显示舍入、随机顺序都不是键。

Token 三列是组内求和：Q9；TREC = DL20+DL22；BEIR = COVID+DBpedia+Robust04。Latency 列是六集等权平均，单位秒。

复算：`PYTHONPATH=src python3 -m unittest discover -s src/tests`，然后 `PYTHONPATH=src python3 -m emit`。不要手改 `tex/generated/` 里的数字。
