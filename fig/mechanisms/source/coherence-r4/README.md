# Mechanism family: R4

The selected artwork uses one serif font family, round item marks and a white
background. A solid neutral ring is a buffered/stored item; a dashed ring is an
unread item. Gold is reserved for the local action (newly read item, active
refresh path or decisive slot), not for a data series. Soft green denotes
emitted rows or winners, not a pointer choice. The accepted external-merge
figure keeps its existing blue dashed boundaries for groups of runs.

The LT figure retains two snapshots of the same tree. Its input group, complete
rank order, and both local replays are recorded in lt/states.json. The original
example is retained as lt/baseline.pdf. Run lt/render.py to regenerate SVG and
export with Inkscape.
