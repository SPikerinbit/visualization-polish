\section{Conclusion}
\label{sec:conclusion}
Executing declarative semantic \textsf{ORDER BY} over bounded-capacity listwise LLMs requires jointly optimizing which tuples enter each prompt and how returned local permutations advance global or prefix order. We presented a cost-effective multi-way merge framework combining Sliding-Window Merge (SW) and Segmented Loser-Tree Merge (LT($h$)), unifying pass-materialized Full ranking with a root-driven demand-pull producer tree for streaming \LIMIT~$K$ queries. Without ground-truth labels or pilot model calls, our runtime planner profiles fixed request headers ($H$) and per-item token costs ($L$), replays cached finite-execution schedules, and jointly selects the merger family, fan-in $k$, and quota or segment length $h$ across output demands and KV prefix-cache regimes. Future work includes adaptive interleaving estimation for skewed inputs and holistic optimization across multi-operator semantic query plans.
