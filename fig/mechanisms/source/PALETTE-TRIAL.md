# Figure design trial (unpublished)

The existing review baseline is saved on `baseline/visual-review-r1`; the experiment branch is separate. The first pass tests palette roles without changing scientific structure.

Source inspiration: Liu et al., [Selective Late Materialization in Modern Analytical Databases](https://www.vldb.org/pvldb/vol18/p4616-liu.pdf), Figs. 6–7. The following flat values were sampled from the reference screenshot: yellow `#FFF2CC / #FFD966 / #BF9000`; green `#E2F0D9 / #A9D18E / #548235`; blue `#DEEBF7 / #9DC3E6 / #2E75B6`; neutrals `#D6DCE5 / #767171 / #44546A`. Reused design rule: light stage backing, clear node fills, stronger strokes for actions. Existing figures retain a white page and their data/mode semantics.

Do not interpret current layout-preview values as experiment observations.
